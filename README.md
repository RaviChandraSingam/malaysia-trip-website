# Malaysia · Our Family Adventure 

Static, mobile-friendly family trip dashboard for 14–21 October 2026.

## Run

Open https://ravichandrasingam.github.io/malaysia-trip-website/. No build step or dependencies are required.

## Edit

The HTML, CSS, SVG artwork and JavaScript are in `index.html`. The `seed`, `events` and `food` objects define the published itinerary. 

Personal edits, travel notes and checklists use browser localStorage; they are not shared between devices. Use the site’s JSON export/import for backups.
